# Сервис поиска свободных аудиторий

Консольное приложение для учёта аудиторного фонда и бронирования помещений.

## Возможности

- просмотр и поиск аудиторий;
- проверка вместимости;
- проверка доступности на дату;
- создание и отмена бронирований;
- сортировка аудиторий по вместимости;
- работа с пользователями: добавление, поиск, просмотр;
- сохранение данных в JSON-файлах.

## Структура проекта

- `main.py` — точка запуска, меню;
- `rooms.py` — работа с аудиториями;
- `users.py` — работа с пользователями;
- `bookings.py` — работа с бронированиями;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.

## Требования

- Python 3.x
- pytest
- flake8

Установка зависимостей:

    pip install -r requirements.txt

## Запуск программы

    python main.py

## Запуск тестов

    python -m pytest

## Проверка качества кода

    python -m flake8

## Формат хранения данных

- `data/rooms.json` — словарь аудиторий (id → название, вместимость);
- `data/users.json` — словарь пользователей (id → имя, email);
- `data/bookings.json` — список бронирований (id, room_id, user_id, date, is_cancelled).

Отменённое бронирование не удаляется из файла, а помечается `is_cancelled = true`.
