# Roomly — сервис поиска свободных аудиторий

Консольное приложение для управления аудиторным фондом и бронирования помещений.

## Возможности

- просмотр и поиск аудиторий;
- проверка вместимости и фильтрация по вместимости;
- сортировка аудиторий;
- проверка доступности на дату;
- создание и отмена бронирований;
- работа с пользователями: добавление, поиск, просмотр;
- хранение данных в JSON-файлах между запусками.

## Предметная область

Основные сущности:

- **Room** — помещение;
- **User** — пользователь;
- **Booking** — бронирование помещения пользователем.

`Booking` связывает `Room` и `User`. На одну дату у одного помещения
может быть только одно **активное** бронирование. Отменённое бронирование
не блокирует помещение.

## Основные классы

### `Room`

Атрибуты: `id`, `name`, `capacity`.

Методы:

- `is_suitable_for(people_count)` — проверка вместимости;
- `__str__()` — строковое представление.

### `User`

Атрибуты: `id`, `name`, `email`.

Методы:

- `from_data(data)` — создание из словаря (`@classmethod`);
- `__str__()` — строковое представление.

### `Booking`

Атрибуты: `id`, `room` (объект Room), `booking_date`, `user` (объект User), `is_cancelled`.

Методы:

- `cancel()` — отмена бронирования;
- `__str__()` — строковое представление.

## Требования

- Python 3.10+
- pytest
- flake8

Установка зависимостей:

    pip install -r requirements.txt

## Запуск

    python main.py

## Тесты

    python -m pytest -v

## Линтер

    python -m flake8

## Хранение данных

- `data/rooms.json` — список объектов-аудиторий;
- `data/users.json` — список пользователей;
- `data/bookings.json` — список бронирований (с `room_id` и `user_id`).

При загрузке JSON-данные преобразуются в объекты `Room`, `User`, `Booking`.
При сохранении объекты преобразуются обратно в JSON.
